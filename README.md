🖼️ Image Gallery

A responsive image gallery built using HTML, CSS, and JavaScript to display images in an attractive and interactive layout.

✨ Features

- Responsive image grid
- Next/previous image navigation
- Lightbox image viewing
- Hover effects and smooth transitions
- Image filtering by category

🛠️ Technologies

- HTML5
- CSS3
- JavaScript

🚀 How to Run

Open "index.html" in your web browser to explore the gallery.
